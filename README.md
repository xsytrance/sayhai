# sayhai

A bright, chaotic-goofy cartoon **desktop companion** — a living face that blinks,
breathes, reacts, remembers you, and grows like a Tamagotchi. Local-first; cloud is
an optional treat, never a dependency.

- [`companion/TAMAGOTCHI_BUILD_PLAN.md`](companion/TAMAGOTCHI_BUILD_PLAN.md) — the full phased build plan
